# R&D Граф знаний горно-металлургической отрасли

MVP для Nornickel AI Hackathon (Задача 2 «Научный клубок»). Единая система поиска и
синтеза знаний по корпусу R&D-документов: естественно-языковой поиск, обзор литературы
со ссылками на первоисточники, разделение отечественной/зарубежной практики, числовые
ограничения, фасетные фильтры, граф связей и экспорт.

## Как это работает

```
Запрос эксперта
   │
   ├─ [точный режим] расширение запроса синонимами (YandexGPT)
   │
   ▼
inverted index → BM25   (лексический ретривер по ~300 тыс. чанков полного текста)
   │  + фильтры: год, материал, происхождение; буст по числовым ограничениям
   ▼
[точный режим] LLM listwise-реранк top-N → top-k (YandexGPT — замена cross-encoder)
   ▼
синтез ответа (YandexGPT): обзор + консенсус/разногласия + пробелы + рекомендации,
   каждое утверждение со ссылкой [D-XXXX] на первоисточник
   +
подграф документ↔сущность (газеттир по извлечённым чанкам) · метаданные (уверенность,
   актуальность, источники) · числовые факты · экспорт MD/JSON-LD/PDF
```

- **Быстрый режим** (~5 c): BM25 + синтез, 1 вызов LLM.
- **Точный режим** (~10–12 c): + расширение запроса + LLM-реранк, 3 вызова LLM.
- Ответы кэшируются: повтор запроса — мгновенно.

## Требования

- **Python 3.12+**
- **Node.js 18+** и npm
- **Ключи Yandex Cloud** (YandexGPT + Embeddings): `YC_API_KEY`, `YC_FOLDER_ID`
  Без ключей поиск и синтез не работают (BM25 отдаёт фрагменты, но ответ не синтезируется).
- **Данные** в `data/` (см. раздел «Данные»).

## Установка

```bash
git clone <repo> && cd nornikel

# Python-окружение
python3 -m venv .venv
source .venv/bin/activate          # fish: source .venv/bin/activate.fish
pip install -r requirements.txt

# Ключи Yandex Cloud
cp .env.example .env               # затем впишите YC_API_KEY и YC_FOLDER_ID

# Фронтенд
cd web && npm install && cd ..
```

## Данные

Система работает поверх готовых артефактов в `data/` (они большие/сгенерированные и не
лежат в git — берутся из архива сдачи на облачном диске):

| Файл | Размер | Назначение | Обязателен |
|---|---|---|---|
| `data/corpus_full.json` | ~432 МБ | полный текст корпуса (2017 док, ~300 млн симв) | **да** |
| `data/graph.json` | ~27 МБ | старый граф — источник словаря сущностей (газеттир) | **да** |
| `data/embeddings.npz` | ~2 МБ | эмбеддинги (загружаются на старте) | **да** |
| `data/bm25_index.pkl` | ~925 МБ | кэш BM25-индекса | нет — **соберётся сам** при первом старте (~25 c) |

**Пересобрать корпус из исходных документов** (если есть папка «Источники информации»):

```bash
# путь к папке с PDF/docx/xls; или переменная NORNIKEL_SRC
python scripts/build_corpus_full.py "/путь/к/Задача 2. Научный клубок"
rm -f data/bm25_index.pkl          # чтобы индекс пересобрался под новый корпус
```

## Запуск

Одной командой (поднимает бэкенд :8000 и фронтенд :5173):

```bash
bash scripts/run_dev.sh
```

Либо вручную в двух терминалах:

```bash
# терминал 1 — бэкенд (первый старт собирает BM25-индекс ~25 c)
.venv/bin/uvicorn api.main:app --port 8000

# терминал 2 — фронтенд
cd web && npm run dev
```

Откройте **http://localhost:5173**

> Ссылки «открыть оригинал» у источников работают, если доступна папка исходников.
> Укажите её через переменную окружения перед запуском бэкенда:
> `export NORNIKEL_SRC="/путь/к/Задача 2. Научный клубок"`

## Использование

- **Поиск** — задайте вопрос на естественном языке (примеры-чипы на главной).
- **Режим** «Точно / Быстро» — переключатель над ответом (точнее vs быстрее).
- **Фильтры** — практика (отеч./зарубеж.), диапазон лет, материал.
- **Роли** (RBAC) — Гость / Исследователь / Рук. R&D (в шапке).
- **Тема** — светлая/тёмная (иконка в шапке).
- **Вкладки** — Ответ · Граф связей (подграф результата) · (Противоречия — в разработке).
- **Экспорт** — Markdown / JSON-LD / PDF (кнопки над ответом).
- **Источники** — карточки с именем файла, категорией, годом, числовыми фактами и ссылкой
  на оригинал; клик по `[D-XXXX]` в ответе подсвечивает источник.

## API

| Метод | Эндпоинт | Назначение |
|---|---|---|
| GET | `/api/meta` | типы узлов, роли, фасеты (материалы, годы), примеры |
| POST | `/api/search` | поиск + синтез + подграф + метаданные (см. `SearchReq`) |
| GET | `/api/graph?role=` | глобальный граф знаний |
| GET | `/api/suggest?q=` | автодополнение |
| GET | `/api/doc/{id}` | отдать оригинальный файл документа |

Пример:

```bash
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{"query":"удаление SO2 из отходящих газов","role":"Рук. R&D","fast":true}'
```

## Структура

```
api/main.py            FastAPI: /api/meta, /api/search, /api/graph, /api/doc, /api/suggest
query/retrieval.py     inverted index + BM25 по чанкам полного текста (кэш на диск)
query/rerank.py        расширение запроса + LLM listwise-реранк (YandexGPT)
query/constraints.py   извлечение числовых ограничений и фактов
query/entities.py      газеттир сущностей → подграф на новом корпусе + фасеты
query/engine.py        оркестрация поиска, синтез ответа, метаданные, RBAC
scripts/build_corpus_full.py   полный ingest документов (PDF/docx/xls/pptx) → corpus_full.json
scripts/yandex.py      клиент Yandex Cloud (completion + embeddings, кэш)
scripts/load_neo4j.py  (опц.) выгрузка графа в Neo4j
web/                   React + Vite фронтенд
  src/App.jsx          состояние, режимы, фильтры, вкладки
  src/GraphCanvas.jsx  force-directed граф (тема-зависимый)
  src/Panels.jsx       роли, фильтры, ответ, источники
  src/Export.jsx       экспорт MD / JSON-LD / PDF
app.py                 устаревший Streamlit-прототип (не нужен для основного приложения)
```

## Стек

Поиск: **inverted index + BM25** (scipy/scikit-learn) → **LLM listwise-реранк** и синтез
(**YandexGPT**). Эмбеддинги — **Yandex Embeddings**. Парсинг документов — PyMuPDF,
python-docx, openpyxl, python-pptx. API — **FastAPI**. Интерфейс — **React + Vite**.
Опционально — выгрузка графа в **Neo4j**.

## Диагностика

- **Бэкенд не стартует / `FileNotFoundError`** — нет файлов в `data/` (см. «Данные»).
- **Ответ «LLM недоступен»** — не заданы `YC_API_KEY` / `YC_FOLDER_ID` в `.env`.
- **Первый запрос долгий** — на старте собирается BM25-индекс (~25 c), далее из кэша.
- **Ссылка на оригинал 404** — не задан `NORNIKEL_SRC` или нет папки исходников.
- **Порт занят** — освободите 8000/5173 (`lsof -ti:8000 | xargs kill`).
